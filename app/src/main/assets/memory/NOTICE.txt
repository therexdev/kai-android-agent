This distribution includes the publisher's unmodified ONNX model_qint8_arm64.onnx,
renamed minilm-l6-v2-qint8.onnx, plus its unmodified vocab.txt, tokenizer_config.json,

KAI supplies its own Kotlin BERT-uncased WordPiece implementation, mean pooling,
L2 normalization, integrity checks, and phone-local indexing integration. Tokenizer
reference fixtures are checked against the publisher's pinned tokenizer.json.

Limits: English sentence/short-paragraph model, up to 256 WordPieces including
special boundary tokens. Longer text is truncated for this embedding only; the
original stored fact remains intact. Semantic similarity is a retrieval signal,
not a test of factual equivalence, truth, identity, permission, or contradiction.
Model weights, tokenization and inference are bundled and work without downloads,
model API credentials or network access. The model is not a chat/agent model.

Every persisted vector must be derived from a current fact revision and exact
source-text hash. Corrections, forgotten facts, revoked source access and changed
dependencies invalidate the vector. Scope/permission checks precede retrieval;
the vector never authorizes access to its source. Changing the model ID requires
rebuilding vectors. Do not compare vectors produced by different model versions.
