## Behavior and limits

The phone reconciles supported single-valued properties by scope, stable subject ID and property. Corrections retain evidence and supersession history; pending corrections reuse the review card. Similar names never authorize person merges. Original quotations remain evidence, while card summaries and saved facts use extracted values. Unknown wording can use model-proposed normalized claims, which require confirmation. A raw copied command is no longer the default memory fallback.

Existing free-form notes are not bulk-rewritten. A fully understood older pending transcript card can be converted in place when revisited, and a complete simple older surname note can be superseded during correction; a mixed note is preserved so other information is not silently lost. Ambiguous old spelling cards cannot be confirmed until clarified. Actual speech-recognition output and live model instruction-following require a physical-phone retest. This update does not recover absent phone data.
