# KAI Android 0.5.11 test release

All-chats reports for comparing repeated attempts. Version code 51, package `com.kai.agent.preview`, existing signer and SQLCipher schema 3. Install over the existing app; no server update, new account connection or model change is needed.

1. Install the update before collecting a new batch. Previously discarded trace details cannot be reconstructed.
2. Run 10–20 attempts in separate regular chats. Include successes as well as failures. Avoid deleting/forgetting data or changing credentials during collection: these privacy actions clear diagnostics.
3. When work has finished, open Settings, scroll to the bottom, tap Report, leave All saved chats selected and Save report.
4. Save the ZIP and attach that one file. The report contains personal content across all included chats; nothing is uploaded automatically.
5. Optionally choose This chat only to export an individual attempt.

All saved regular chats are included. Detailed traces are bounded to the 20 most recently traced chats and per-chat limits. The index marks missing/dropped evidence. This update collects comparable evidence; it does not claim to resolve document/email model behavior.
